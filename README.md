# FarmLink

전국 공개 농촌체험지, 체험마을, 농촌여행지를 한 화면에서 탐색하는 농장 연결 지도 MVP입니다.

## 현재 기능

- 장소명, 지역, 품목/프로그램 검색
- 지역/품목/체험/임대 필터
- 지도형 마커 클릭
- 농장 상세 정보 패널
- 공개 체험지 카드 목록
- 출처 보기 및 길찾기 연결
- Vercel 정적 배포

## 데이터 수정

농장/체험지 데이터는 `script.js`의 `farms` 배열에서 수정할 수 있습니다.

## 현재 데이터 출처

- 웰촌: 농촌여행지, 지도로 보는 농촌여행지, 계절/테마 여행 코스
- 네이버 지도 검색 링크: 길찾기 연결용

연락처, 예약 가능 여부, 임대 가능 여부는 공개 페이지에서 바로 확인되지 않은 항목이 있어 `확인 필요`로 표시합니다.
