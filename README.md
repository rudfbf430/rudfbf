# 오늘의 제철

전국 원예작물의 제철 시기, 주요 산지, 고르는 법, 보관법을 오늘 날짜 기준으로 추천하는 정적 웹 서비스입니다.

## 해결하려는 농업 문제

소비자는 지금 어떤 농산물이 제철인지, 어느 지역 산지가 유명한지, 어떻게 고르고 보관해야 신선하게 먹을 수 있는지 한 번에 알기 어렵습니다. 이 서비스는 월별 제철 원예작물과 산지 정보를 한 화면에서 탐색하게 하여 지역 농산물의 발견성을 높이고, 구매 후 신선도 저하와 음식물 낭비를 줄이는 데 도움을 줍니다.

## 주요 기능

- 오늘 날짜 기준 제철 원예작물 추천
- 월별 제철 작물 필터
- 월별 제철 캘린더
- 지역, 분류, 검색어 기반 작물 탐색
- 작물별 주요 산지, 활용법, 고르는 법, 보관법 제공
- 관심 작물 저장
- 지역별 오늘의 추천
- 반응형 UI

## 데이터 구조

```js
{
  id: "tomato",
  name: "토마토",
  category: "과채류",
  regions: ["부산", "강원", "충남"],
  seasonMonths: [5, 6, 7, 8, 9],
  image: "작물 이미지 URL",
  description: "작물 설명",
  pickTip: "고르는 법",
  storageTip: "보관법",
  uses: ["샐러드", "소스"]
}
```

## 실행 방법

별도 빌드 과정 없이 `index.html`을 브라우저에서 열면 실행됩니다.

## 파일 구성

- `index.html`: 화면 구조와 제출용 서비스 설명
- `styles.css`: 반응형 UI 스타일
- `script.js`: 작물 데이터, 필터링, 오늘 추천 계산 로직
