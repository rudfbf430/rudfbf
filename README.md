# FarmLink

전국 농장 위치, 재배 품목, 규모, 체험 가능 여부, 임대 가능 여부를 한 화면에서 탐색하는 농장 연결 지도 MVP입니다.

## 현재 기능

- 농장명, 지역, 품목 검색
- 지역/품목/체험/임대 필터
- 지도형 마커 클릭
- 농장 상세 정보 패널
- 농장 카드 목록
- Vercel 정적 배포

## 데이터 수정

샘플 농장 데이터는 `script.js`의 `farms` 배열에서 수정할 수 있습니다.
